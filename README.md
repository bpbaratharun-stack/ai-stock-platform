# 🚀 Quantitative AI Market Terminal

Institutional-style AI-powered NSE market intelligence platform built using FastAPI, React, XGBoost, quantitative analytics, and multi-threaded market scanners.

---

# 📌 Project Overview

Quantitative AI Market Terminal is a production-style AI trading analytics dashboard designed for the Indian stock market.

The platform combines:

- Quantitative feature engineering
- Ensemble AI inference
- Multi-threaded NSE scanners
- Market regime analysis
- India VIX volatility modeling
- Live macro news intelligence
- Institutional-grade charting
- Explainable AI diagnostics
